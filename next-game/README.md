# 王道

9×9の盤上で、2人の王が相手の王を追うローカル対戦ゲームです。

## 遊び方

- 対戦相手で「2人対戦」または「CPU対戦」を選べます。CPUレベルは1、2、3、5〜10、100から選べ、高いほど評価上の最善手を選びやすくなります。
- 王をクリックして移動先を選びます。「兵を置く」を選ぶと、空きマスをクリックして兵を配置できます。
- 王は縦・横・斜めの8方向へ、周囲1マス移動できます。隣に自分の兵がいる方向へは、その兵を飛び越えて2マス進めます。
- 自分の兵は王が飛び越せます。相手の兵は進路をふさぎます。
- 兵は1人15枚まで置けます。兵は移動も攻撃もできません。
- 自分の兵は、同じ行・列にそれぞれ3個まで置けます。
- 兵同士は隣り合って置けます。
- 相手の王がいるマスへ自分の王が入ると勝利です。
- 勝利時には勝利画面と紙吹雪の演出が表示されます。

PLAYER 1の王は下段中央、PLAYER 2の王は上段中央から始まります。

## 起動

`index.html` をブラウザで開いてください。
